# תרגיל שיעור 6 — טופס טכני

פרויקט Angular בסיסי לתרגול **Template-driven Forms**.

## הפעלה

```powershell
npm install
npm start
```

הפרויקט יספק את נקודת ההתחלה לבניית טופס הזמנת ביקור טכנאי ב־`src/app/app.html` וב־`src/app/app.css`.

## הפרויקט אינו כולל עדיין

- `ngForm` ו־`ngModel`
- ולידציות
- הודעות שגיאה ועיצוב שדות
- בדיקה ולכידה של שליחת הטופס
